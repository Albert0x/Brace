# Brace 使用文档

[English](./USAGE.md) · 简体中文

Brace 是一款基于 Tauri + Rust 的轻量 Windows 终端,最大特色是**在状态栏实时显示 Claude / Codex 的用量**。本文覆盖日常使用的全部功能。

## 安装

1. 从 [Releases](https://github.com/Albert0x/Brace/releases/latest) 下载 `Brace_x.y.z_x64-setup.exe`,双击运行。
2. **首次安装** Windows SmartScreen 会弹「Windows 已保护你的电脑」——因为安装包尚未做代码签名。点 **更多信息 → 仍要运行** 即可。
3. 装好后 Brace 会自动检查并推送更新,无需再手动下载。

## 界面概览

Brace 采用三栏 + 状态栏布局:

- **顶栏**:标签页、新建标签 `＋`(旁边 `▾` 选 Shell)、搜索框、设置 `⚙`、窗口控制。
- **左侧**:文件树(跟随当前终端目录)。
- **中间**:终端。
- **底部状态栏**:左边是 **AI 用量**(跑 claude/codex 时),右边是字体大小、终端数、主题、编码、系统。

## 标签与 Shell

- **新建标签**:点 `＋` 或按 `Ctrl+T`。新标签**自动继承当前标签的目录**。
- **选择 Shell**:点 `＋` 旁的 `▾`,可选 PowerShell、PowerShell 7、命令提示符(CMD)、Git Bash。Brace 会自动检测系统里装了哪些(Git Bash 从 `git.exe` 反推路径)。
- **关闭标签**:点标签上的 `×` 或按 `Ctrl+W`。
- **切换标签**:`Ctrl+Tab` / `Ctrl+Shift+Tab`。
- 标签标题会智能显示当前目录名。
- **会话恢复**:关掉 Brace 再打开,上次的标签组会原样开回来——每个标签用的 Shell 和所在目录都记着,连当时选中的是哪个标签也记着。注意恢复的是**新的 shell 进程**,不是把上次跑到一半的命令接回来。

## 文件树联动

文件树和终端**双向同步**:

- 在终端 `cd` 到某目录,左侧文件树自动跟着切换根目录。
- 在文件树里**双击文件夹**,终端自动 `cd` 过去。
- **自动刷新**:在终端里 `mkdir` / `rm` / 切分支之后,文件树会自己更新,不用手动点。
- 点右上角 `⟳` 手动刷新:会把根目录和所有**已展开**的子目录一起重新读一遍。
- **增删改**:右键菜单里可以新建文件/文件夹、重命名、删除、复制路径、在资源管理器中显示。空白处右键则是对根目录操作。右上角 `＋` 是在根目录下快速新建文件。
- `.gitignore` / `.env` 这些**默认就显示**——在 Windows 上它们并不是隐藏文件。真正带隐藏属性的（比如 `.git` 目录）默认藏起来,想看就到 设置 → 常规 → 打开「显示隐藏文件」。

> 原理:Brace 给每个 Shell 注入了 prompt,用 OSC 9;9 转义序列上报当前目录,PowerShell / CMD / Git Bash 各有对应写法。

> **删除走回收站**,不是永久删除,误删了可以还原。Brace 不提供永久删除——真要彻底删,
> 终端就在旁边。

> 监听的是**根目录加上所有已展开的目录**,每个都只盯一层,不递归。因为当前目录常常
> 就是用户主目录,递归监听会把 AppData、OneDrive、浏览器缓存的读写全都收进来,
> 量大且没有意义。没展开的目录不监听,反正也看不见。

## Git 提交面板

状态栏左下角的 `⑂ 分支名 ±N` 就是入口,点一下打开。它只做一件事:**把手头这批改动提交掉**。

- **勾选要提交的文件**。默认全选,取消勾选就不会进这次提交。
- **点文件名展开 diff**,绿色是新增行、红色是删除行。未跟踪的新文件会整份显示成新增。
- **选提交类型**(可选):默认给的是 Conventional Commits 那套通用词表(`feat` `fix` `docs` `style` `refactor` `perf` `test` `build` `ci` `chore` `revert`),右边可以填范围。选了会拼成 `feat(git): 描述`,下面一行预览显示最终写进 git 的是什么。再点一次可取消——临时提交不想守规范时不该被逼着守。
- 团队用的是别的词表?**设置 → 常规 → Git → 提交类型**,逗号分隔改成你们自己的就行,留空恢复默认。
- 写提交信息,点 **Commit**,或者 `Ctrl+Enter`。**Commit & Push** 是提交完顺带推送。
- 出错(没配 user.name、push 被拒、没有 upstream……)会把 git 的原话显示出来,不做加工。

> **只提交你勾选的文件。** 如果你之前在终端里 `git add` 过别的东西,它们不会被这次提交
> 捎带上——面板提交时带了路径限定。这一点和直接敲 `git commit` 不一样,后者会把整个
> 暂存区都提交掉。

> **不做逐行暂存。** 想挑某个文件里的部分行提交,用终端里的 `git add -p`。在终端的侧边
> 面板里重做一个 VS Code 源代码管理器没有意义,那不是这个面板要解决的问题。

文件树上的颜色和角标是同一套 git 状态:黄色 `M` 改动、绿色 `A`/`?` 新增或未跟踪、
红色 `D` 删除、蓝色 `R` 重命名;文件夹里有改动时右边点一个小黄点。被 git 忽略的文件
会变灰。这套装饰可以在 设置 → 常规 → **Git 装饰** 里关掉。

## AI 用量显示（特色）

这是 Brace 独有的功能——**在状态栏实时显示 Claude / Codex 的用量**,只在当前标签**真的在跑** claude 或 codex 时才显示(进程检测)。

### Claude

Claude 的官方用量(context / 5小时 / 周额度 + 重置时间)走 Claude Code 的 **statusLine** 通道,需要先启用一次:

1. 设置 → **常规** → 拉到底「**Agent Usage**」→ 打开「在状态栏显示 Claude 用量」开关。
   - 这会往你的 `~/.claude/settings.json` 挂一个采集脚本(如果你已经配过别的 statusLine,Brace 不会覆盖,会提示)。
2. **启动 / 重启 claude**(statusLine 是 claude 启动时读配置的,已经开着的要 `/exit` 重开)。
3. 发一条消息。官方额度数据**要 API 响应后才有**,发过消息状态栏就会显示。

状态栏读法:`[模型]  Context 61%  5h 35% 4h7m  7d 48% 35h`
- **Context**:当前会话上下文窗口占用。
- **5h / 7d**:5小时窗口、周窗口的额度用量 %,后面是重置倒计时。

### Codex

Codex **无需任何配置**——直接跑 `codex`,状态栏自动显示 `Codex  Context x%  xxK tok`(上下文占用 + 会话累计 token)。

> Codex 只有 context 和 token,**没有** 5小时/周额度——因为 codex 本地会话文件里的 rate_limits 字段通常为空,数据源就没有。

### 给 Claude 粘贴图片

在 Brace(以及任何终端)里给 claude 粘图片,用 **`Alt+V`**,**不是 `Ctrl+V`**。因为 `Ctrl+V` 被终端占用当「粘贴文本」了,图片传不到 claude;`Alt+V` 是 Claude Code 在 Windows 上专门的图片粘贴键,识别后会插入 `[Image #1]` 占位。

## 配置组：切换 API 与代理（特色）

配置组（Profile）就是一组环境变量。选中哪一组，**之后新开的终端**就带着那组变量启动。
常见用途是在多个 Claude 中转 API 之间切换，或者给终端单独挂代理。

### 建一个配置组

设置 `⚙` → **配置组** → `＋ 新建配置组`：

1. 给它起个名字，比如「公司中转」。
2. 点 **模板 → Claude Code**，自动填好 `ANTHROPIC_BASE_URL` / `ANTHROPIC_AUTH_TOKEN` / `ANTHROPIC_MODEL` 三个变量名。
3. 填上各自的值，点 **保存**。

模板还有 **Codex / OpenAI** 和 **代理**。点 **读取系统代理填入** 会把 Windows 当前的系统代理
（Clash 那种）直接写进 `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY`，不用自己去注册表里翻。

### 切换

状态栏左下角的 `🔑` 徽标显示当前生效的配置组，点它就能切，选「关闭」则什么都不注入。

> **只对新开的标签生效。** 已经跑起来的进程改不了自己的环境变量，这是操作系统的规矩。
> 切完配置组记得 `Ctrl+T` 开个新标签。

### 密钥怎么存的

- 变量行右边的 🔒 表示这是密钥。变量名里带 `TOKEN` / `KEY` / `SECRET` / `PASSWORD` 的会自动上锁，也可以手动点开或关上。
- 上锁的值用 **Windows DPAPI 按你的用户账户加密**后才写进磁盘，配置文件被同步到网盘或误发给别人，里面的密文别人也解不开。
- 配置文件在 `%APPDATA%\com.brace.dev\profiles.json`。因为绑定了当前 Windows 用户，**换台机器复制过去密钥是解不开的**，需要重新填。
- 密钥的明文只在写入和注入的瞬间存在于内存里，界面上永远不回显（只显示「已保存」或「未设置」）。
- 改了一个已有密钥的**变量名**，等于换了一把锁——界面会立刻变回「未设置」，提醒你重新填值。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+T` | 新建标签 |
| `Ctrl+W` | 关闭当前标签 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一个 / 上一个标签 |
| `Ctrl+F` | 聚焦搜索框 |
| `Ctrl+Shift+C` | 复制选中内容 |
| `Ctrl+Shift+V` | 粘贴(带 bracketed paste,claude/vim 能区分粘贴与手打) |
| `Ctrl+=` / `Ctrl+-` | 放大 / 缩小字体 |
| `Ctrl+0` | 字体恢复默认(14px) |
| `Alt+V` | (在 claude 里)粘贴剪贴板图片 |
| 右键 | 复制 / 粘贴 / 全选 / 清屏菜单 |

## 主题与背景

设置 → **主题**:

- **五款内置主题**:HyperDark(默认近黑玻璃)、Tokyo Night、Dracula、Nord、Gruvbox,点一下即时切换。
- **背景图**:点「选择图片…」设任意图片为毛玻璃背景,拖动「遮罩浓度」滑块调整明暗;点「清除」还原。
- **外观模式**:设置 → 常规 → 外观,可选跟随系统 / 浅色 / 深色。

---

## 设置

设置面板(点 `⚙`)分四个标签:

- **常规**:外观模式、界面语言(中/英)、UI 缩放、显示隐藏文件、Git 装饰、WebGL 渲染、光标闪烁、**Agent Usage**(Claude 用量开关)。
- **配置组**:环境变量配置组，见[上一节](#配置组切换-api-与代理特色)。
- **主题**:主题选择、背景图。
- **关于**:版本信息、检查更新、GitHub / 反馈链接。

---

## 自动更新

Brace 内置签名版自动更新:

- 设置 → 关于 → **检查更新**。有新版会提示,确认后自动下载并重启。
- 从 v0.1.2(改名 Brace 后的首版)开始,更新链路正常;更早的 HyperTerminal 因为 bundle id 变了,需要手动装一次 Brace。
