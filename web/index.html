// what's inside

Everything a terminal should be — nothing it shouldn't.

The essentials done right, plus the touches you didn't know you needed.

⌗

Multi-tab shells

Run PowerShell, CMD and Git Bash side by side. New tabs inherit your current directory automatically.

↹

Two-way file tree

The sidebar follows your terminal's cd, and double-clicking a folder cd's the terminal right back.

◑

Themes & wallpaper

Five built-in themes, System / Light / Dark, and set any image as a frosted-glass background.

⟳

Auto-updates

Signed, one-click updates straight from GitHub Releases. Check, download, relaunch — done.

文

English & 中文

Full bilingual interface with an instant language switch. Adding more locales is a two-line change.

⚡

Native & light

Tauri + Rust core with a real ConPTY backend and WebGL rendering. Fast to launch, tiny to install.
