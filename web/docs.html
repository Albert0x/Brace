Brace User Guide

Lightweight Windows terminal · Tauri + Rust

Brace's standout feature is showing your Claude / Codex usage live in the status bar. This guide covers everything you'll use day to day.

Installation

  • Download Brace_x.y.z_x64-setup.exe from Releases and run it.
  • On first launch Windows SmartScreen may warn about an unrecognized app (the installer isn't code-signed yet) — click More info → Run anyway.
  • Once installed, Brace checks for and delivers updates on its own.

Interface overview

Three columns plus a status bar:

  • Top bar — tabs, new-tab ＋ (with ▾ to pick a shell), search, settings ⚙, window controls.
  • Left — file tree, follows the active terminal's directory.
  • Center — the terminal.
  • Bottom status bar — AI usage on the left (when claude/codex runs), font size / terminal count / theme / encoding / OS on the right.

Tabs & shells

  • New tab: click ＋ or press Ctrl+T — new tabs inherit the current directory.
  • Pick a shell: the ▾ next to ＋ — PowerShell, PowerShell 7, CMD, Git Bash (auto-detected).
  • Close: × on the tab or Ctrl+W. Switch: Ctrl+Tab / Ctrl+Shift+Tab.

File tree sync

The tree and terminal stay in two-way sync:

  • cd in the terminal → the tree re-roots there.
  • Double-click a folder in the tree → the terminal cds there.
  • Click ⟳ to refresh; enable Show hidden files in Settings → General for dotfiles.

AI usage display (the highlight)

Your Claude / Codex usage, live in the status bar. It only shows when the active tab is actually running claude or codex.

Claude

Claude's official usage (context / 5-hour / weekly + reset times) comes through Claude Code's statusLine channel — enable it once:

  • Settings → General → Agent Usage → turn on "Show Claude usage in status bar" (installs a collector into ~/.claude/settings.json; won't overwrite an existing statusLine).
  • Start / restart claude (statusLine is read at launch), then send a message — quota data appears after the first API response.

Reading the bar: [model] Context 61% · 5h 35% 4h7m · 7d 48% 35h — context window fullness, plus 5-hour and weekly quota with reset countdowns.

Codex

No setup — just run codex and the bar shows Codex Context x% · xxK tok.

Codex shows only context and tokens, not 5-hour/weekly limits — its local session files leave the rate_limits fields empty.

Pasting images to Claude

Use Alt+V, not Ctrl+V. Ctrl+V is claimed by the terminal as "paste text" so the image never reaches claude; Alt+V is Claude Code's dedicated image-paste key on Windows.

Themes & backgrounds

  • Five themes: HyperDark, Tokyo Night, Dracula, Nord, Gruvbox — switch instantly.
  • Background image: set any image as a frosted-glass background with an overlay slider.
  • Appearance: System / Light / Dark in Settings → General.

Settings

  • General — appearance, language (en/zh), UI zoom, hidden files, Git decorations, WebGL, cursor blink, Agent Usage.
  • Themes — theme selection and background image.
  • About — version, check for updates, GitHub / issue links.

Auto-updates

Settings → About → Check for updates. New versions download and relaunch automatically. The update chain works from v0.1.2 onward; older HyperTerminal installs have a different bundle id, so install Brace once by hand.

Questions or ideas? Open a GitHub Issue.

Brace 使用文档

轻量 Windows 终端 · Tauri + Rust

Brace 最大的特色是在状态栏实时显示 Claude / Codex 的用量。本文覆盖日常使用的全部功能。

安装

  • 从 Releases 下载 Brace_x.y.z_x64-setup.exe 运行。
  • 首次安装 Windows SmartScreen 会弹「Windows 已保护你的电脑」(安装包尚未代码签名) — 点 更多信息 → 仍要运行。
  • 装好后 Brace 会自动检查并推送更新。

界面概览

三栏 + 状态栏布局:

  • 顶栏 — 标签、新建 ＋(旁 ▾ 选 Shell)、搜索、设置 ⚙、窗口控制。
  • 左侧 — 文件树,跟随当前终端目录。
  • 中间 — 终端。
  • 底部状态栏 — 左边 AI 用量(跑 claude/codex 时),右边字体/终端数/主题/编码/系统。

标签与 Shell

  • 新建标签:点 ＋ 或 Ctrl+T — 新标签自动继承当前目录。
  • 选择 Shell:＋ 旁的 ▾ — PowerShell、PowerShell 7、CMD、Git Bash(自动检测)。
  • 关闭:标签上 × 或 Ctrl+W。切换:Ctrl+Tab / Ctrl+Shift+Tab。

文件树联动

文件树和终端双向同步:

  • 终端 cd → 文件树跟着切换根目录。
  • 文件树里双击文件夹 → 终端自动 cd 过去。
  • 点 ⟳ 刷新;设置 → 常规 → 显示隐藏文件 可看 dotfiles。

AI 用量显示 (特色)

在状态栏实时显示 Claude / Codex 用量,只在当前标签真的在跑 claude 或 codex 时显示。

Claude

Claude 官方用量(context / 5小时 / 周 + 重置时间)走 Claude Code 的 statusLine 通道,需先启用一次:

  • 设置 → 常规 → Agent Usage → 打开「在状态栏显示 Claude 用量」(往 ~/.claude/settings.json 挂采集脚本;已有别的 statusLine 不覆盖)。
  • 启动 / 重启 claude(statusLine 启动时读),发一条消息 — 额度数据要 API 响应后才有。

状态栏读法:[模型] Context 61% · 5h 35% 4h7m · 7d 48% 35h — 上下文占用,以及 5小时、周额度用量 % 加重置倒计时。

Codex

无需配置 — 直接跑 codex,状态栏自动显示 Codex Context x% · xxK tok。

Codex 只有 context 和 token,没有 5小时/周额度 — 它本地会话文件里的 rate_limits 通常为空。

给 Claude 粘贴图片

用 Alt+V,不是 Ctrl+V。Ctrl+V 被终端占用当「粘贴文本」,图片传不到 claude;Alt+V 是 Claude Code 在 Windows 上专门的图片粘贴键。

主题与背景

  • 五款主题:HyperDark、Tokyo Night、Dracula、Nord、Gruvbox — 即时切换。
  • 背景图:设任意图片为毛玻璃背景,配遮罩浓度滑块。
  • 外观:设置 → 常规 — 跟随系统 / 浅色 / 深色。

设置

  • 常规 — 外观、语言(中/英)、UI 缩放、隐藏文件、Git 装饰、WebGL、光标闪烁、Agent Usage。
  • 主题 — 主题选择、背景图。
  • 关于 — 版本、检查更新、GitHub / 反馈链接。

自动更新

设置 → 关于 → 检查更新。有新版自动下载并重启。更新链路从 v0.1.2 起正常;更早的 HyperTerminal 因 bundle id 不同,需手动装一次 Brace。
